## Implementation guardrails

- Follow [root AGENTS.md](../../AGENTS.md), [Engine Invariants](../architecture/INVARIANTS.md), [Quality Gates](../architecture/GATES.md) (`./scripts/check.sh` before every commit/push), and each touched package's local `AGENTS.md`.
- **Never silently promote a *Proposed* ADR:** Phase 2 (`spawn-cli` shader cook) does not start until Phase 0 records explicit owner acceptance of [ADR-0014](../adr/0014-shader-toolchain.md) and Slang license verification. Keep [ADR-0020](../adr/0020-memory-strategy.md) and [ADR-0022](../adr/0022-repository-layout.md) `Proposed` unless the owner explicitly accepts them.
- **Approved dependencies only (`SPN-INV-023`):** Do not add `serde_json`, `tempfile`, `thiserror`, `anyhow`, `shaderc`, `naga`, `spirv-reflect`, `wgpu`, or `gpu-allocator`. Use `std::env::temp_dir()` with unique subdirectories in CLI tests, hand-written located error types ([ADR-0009](../adr/0009-error-handling-and-diagnostics.md)), and crates listed for the target package in [DEPENDENCIES.md](../DEPENDENCIES.md).
- **Keep CI headless and compiler-free (`SPN-INV-009`, `083`):** Default workspace builds and tests must never require `slangc`, Wayland, or a Vulkan ICD. Never commit generated `.spv` files; synthesize minimal SPIR-V word arrays in Rust for unit/GPU-RHI tests where `slangc` is absent.
- **Strict genre neutrality (`SPN-INV-003`):** Keep camera types, input action names, and procedural test geometry completely genre-agnostic (`FreeCamera`, `MoveForwardBack`, `LookYaw`, etc.).
- **Error-code continuity:** Start new `spawn-render` error codes at `REND-0010` and new `spawn-engine` error codes at `ENGN-0008`; never reuse or renumber existing codes.
