## Manual smoke tests (record environment)

On **at least one explicitly named tested platform** (first target: the reference hardware in root [Accepted Decisions](../../AGENTS.md#accepted-decisions) — AMD Ryzen 5 1600, AMD Radeon RX 460 Polaris / RADV, Linux/Wayland/Hyprland, with `VK_LAYER_KHRONOS_validation` + `VK_KHRONOS_VALIDATION_VALIDATE_SYNC=true`):

1. **Offline shader cook ([ADR-0014](../adr/0014-shader-toolchain.md)):** Record pinned `slangc` version, run `cargo run -p spawn-cli -- shaders build`, verify exit `0` and uncommitted SPIR-V + reflection artifacts in build output; verify wrong/missing `slangc` (`PATH` probe) prints a `CLI-0001`+ report and exits nonzero.
2. **Interactive 3D scene & camera:** Launch `spawn-engine` with Khronos validation + sync validation enabled; confirm procedural 3D meshes appear with correct perspective, right-side-up orientation (`+Y` up), backface culling, and front-to-back reversed-Z occlusion.
3. **Controls & cursor capture:** Toggle cursor lock (`CursorGrabMode::Locked`), rotate yaw/pitch smoothly via unaccelerated relative mouse motion (confirm pitch clamps cleanly near straight up/down without flipping), translate along forward/back, right/left, and up/down axes, and confirm releasing focus or toggling unlock restores normal cursor behavior without stuck movement.
4. **Resize, suspend & close:** Exercise tiling/floating/pixel resizes (verifying swapchain + `D32_SFLOAT` depth recreation without visual corruption or clock reset), zero-size/minimized suspension where supported by the compositor, and clean close via `Escape` and compositor `xdg_toplevel.close`.
5. **Failure diagnostics & resource hygiene:** Probe missing cooked shader directory (`REND-0010`+ / `ENGN-*`), unavailable display (`ENGN-0004`), and unavailable Vulkan driver (`ENGN-0005`); record steady-state frame rate, CPU time, GPU allocator block usage, and `validation_errors=0`.

A Linux/Wayland smoke run does **not** claim Windows or X11 support (`SPN-INV-090`).

### Owner interactive verification protocol (pending execution for Gate G3)

Execute the following steps interactively on the reference Linux/Wayland/Hyprland + RX 460 machine and record the observed result in [Recorded smoke runs](#recorded-smoke-runs):

1. **Cook shaders and launch interactively with Khronos validation + sync validation:**
   ```bash
   PATH="$HOME/.local/bin:$PATH" cargo run -p spawn-cli -- shaders build
   VK_INSTANCE_LAYERS=VK_LAYER_KHRONOS_validation VK_KHRONOS_VALIDATION_VALIDATE_SYNC=true cargo run
   ```
   - **Pass condition:** Window opens with the procedural 3D scene visible (`+Y`-up ground checkerboard grid with `+X` red strip, `-2.0 m` coral cube occluding `-5.0 m` cyan cube, `-X` green column, gold/teal octahedron, `-25.0 m` gateway, `-200.0 m` blue tower); `stderr` prints the RADV RX 460 device header and `validation on` with zero validation errors.
2. **Verify unlocked cursor behavior:** Before locking the cursor, move the mouse across the window.
   - **Pass condition:** Camera orientation does **not** rotate while `grab=None`.
3. **Toggle cursor lock (`Tab`) and test relative mouse look:** Press `Tab` once, then move the mouse right, left, up, and down, and push pitch all the way up and all the way down.
   - **Pass condition:** `stderr` logs `cursor_grab=Locked`; cursor hides/locks inside the window; moving mouse right turns right, moving mouse up pitches up; pitching all the way up/down clamps smoothly near vertical without flipping or gimbal snap.
4. **Test 3D camera translation (`W`/`S`/`A`/`D`/`Space`/`LeftControl`):** Hold each movement key individually and in diagonal combinations (`W+D`, `W+D+Space`) while looking in rotated directions.
   - **Pass condition:** Camera translates smoothly along camera-relative forward/back (`W`/`S`), strafe right/left (`D`/`A`), and vertical up/down (`Space`/`LeftControl`) without jitter or speed-up on diagonals.
5. **Test unlock (`Right Mouse Button` or `Tab`) and focus loss:** Unlock with `Right Mouse Button` (or `Tab`), verify mouse movement stops rotating the camera (`cursor_grab=None`), then press `Tab` to re-lock, hold `W`, and switch window focus (`Alt+Tab` / workspace switch) before releasing `W` and refocusing.
   - **Pass condition:** Focus loss (`focused=false`) releases cursor lock (`cursor_grab=None`) and clears held movement so no phantom motion continues after refocusing.
6. **Test live resize (and zero-size/occlusion if compositor supports it):** Drag-resize the floating window (or toggle floating/tiling and change split ratios) while flying around.
   - **Pass condition:** `stderr` reports the new physical dimensions; rendering adapts cleanly without visual corruption, crashes, validation errors, or simulation pose reset.
7. **Exit via `Escape`:** Press `Escape` while the window is focused.
   - **Pass condition:** Process exits with code `0`; `stderr` prints `exited cleanly (ExitAction)`, `validation_errors=0`, and `shutdown_blocks=0 shutdown_live_allocs=0 shutdown_retired_allocs=0`.
